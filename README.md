# Menu Card (HTML & CSS)

This project is a **menu card layout** created using only **HTML and CSS**.

The focus of this project is not functionality, but **presentation** — how information is structured, spaced, and visually prioritized on a page. Menu cards are a great way to practice real-world layout problems, where clarity and readability matter more than effects.

This project helped me improve my understanding of alignment, typography, and responsive design without relying on JavaScript.
